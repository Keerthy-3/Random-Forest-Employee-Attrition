# Employee Attrition Prediction Using Random Forest

## Project Description
This project uses the Random Forest Classification algorithm to predict employee attrition based on employee-related data.

## Dataset
IBM HR Analytics Employee Attrition Dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Files
- `HR-Employee-Attrition.csv` – Dataset
- `Random_Forest_Employee_Attrition_Project.ipynb` – Project implementation
- `Random_Forest_Project_Introduction.pdf` – Project introduction

## Algorithm
Random Forest Classifier

## Evaluation Metrics
Accuracy, Precision, Recall, F1-Score, ROC-AUC, Confusion Matrix, and ROC Curve.
